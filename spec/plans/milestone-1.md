# Milestone 1 – בסיס אפליקציה ושני מסכים מעוצבים

## מטרה
פרויקט Frontend עובד ושני מסכים (בית, אודות) בעיצוב עקבי. הלוח והכפתור **אינם מריצים משחק** באבן דרך זו.

## החלטות תכנון
- **סטאק:** React + TypeScript + Vite, CSS רגיל עם CSS Variables, Vitest + React Testing Library, גופן `@fontsource/heebo` (משקלים 400/600/700) ארוז באפליקציה.
- **נתיב בסיס:** `base: '/SimonNoSkill/'` ב-`vite.config.ts` (חריגה מוסכמת מ-`/Simon/`, ראה `CLAUDE.md`). פיתוח: `http://localhost:5173/SimonNoSkill/`.
- **ניווט:** שני מסכים באותו React Tree, מצב `screen` ב-`App`, בלי Router ובלי טעינת דף. ה-State יישאר ב-`App`, כדי שהמשחק יישרוד מעבר מסכים באבני דרך הבאות.
- **לוח (ADR-1):** מיכל עגול עם CSS Grid 2×2, `direction: ltr`. כל רבע הוא `<button>` עם `aria-label` בעברית, ומיקומו מוגדר ב-`src/game/colors.ts`: ירוק למעלה משמאל, אדום למעלה מימין, צהוב למטה משמאל, כחול למטה מימין. הדיסק המרכזי דקורטיבי בלבד. ברבעים `disabled`, בלי עמעום, עד אבן דרך 2.
- **מחרוזות:** לפי הטקסט במסמכים ולא לפי התמונות: "התחל משחק", "שלב 1 מתוך 10", כותרת אודות "אודות".
- **אודות:** כרטיס "על המשחק", כותרת "10 המשחקים האחרונים", חיווי ריק "אין עדיין משחקים שמורים". כפתור "מחק היסטוריה" לא מוצג, כי אין רשומות.
- **בלי:** Router, PWA, אודיו, קונפטי, localStorage, כפתורי הגדרות. הכול מאבני דרך מאוחרות.
- **פריסה:** ה-Workflow הזמני מוחלף ב-`npm ci` ← typecheck ← test ← build ← פריסת `dist/`. תיקיית `placeholder/` נמחקת.

## תוצאות בנייה
- **גרסאות:** React 19, Vite 8, TypeScript 7, Vitest 5.
- **נבדק בדפדפן באמולציית 375×812:** `lang="he"`, `dir="rtl"`, בלי גלילה אופקית בשני המסכים. מיקומי הרבעים נמדדו: ירוק למעלה משמאל, אדום למעלה מימין, צהוב למטה משמאל, כחול למטה מימין. גופן Heebo נטען מהחבילה, בלי Google Fonts. מעבר בין המסכים בלי טעינת דף.
- **לא נבדק:** מכשיר אמיתי (מגע, אודיו), כי אין עדיין אודיו ומשחק.
- **סטיות מהמסמכים:** הרבעים `disabled` עד אבן דרך 2. טקסט "על המשחק" נוסח בביצוע, כפי שה-PRD מתיר.
- **בעיית ניגודיות ידועה:** טקסט לבן על כפתור `#00A3FF` הוא בניגודיות נמוכה (כ-2.7:1). זה מה ש-`DESIGN.md` קובע, ולכן לא שונה. שווה להחליט עליו באבן דרך 5 (נגישות).
- **Build:** `builds/milestone-1.zip` הוא `dist/` הבנוי עם `base=/SimonNoSkill/`, ולכן הוא תקין רק כשמגישים אותו מתחת לנתיב `/SimonNoSkill/`.
